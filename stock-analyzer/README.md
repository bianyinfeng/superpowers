# 股票量价分析系统

基于K线形态、交易量能、MACD量价关系的A股分析系统。

## 功能特性

- **日线级别分析**: K线形态识别、MACD信号检测、量能因子分析
- **周线级别分析**: 周线趋势确认、多周期共振
- **6大交易策略**: 自动匹配策略并给出止盈止损点位
- **综合建议**: 结合多因子给出方向、仓位、盈亏比

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 分析股票
python main.py 600519    # 贵州茅台
python main.py 000001    # 平安银行
python main.py 300750    # 宁德时代
```

## 因子体系

### K线形态因子 (来源: Steve Nison《日本蜡烛图技术》)

| 形态 | 信号 |
|------|------|
| 锤子线 / 倒锤子线 | 看涨反转 |
| 看涨/看跌吞没 | 反转 |
| 乌云盖顶 / 刺透形态 | 看跌/看涨 |
| 早晨之星 / 黄昏之星 | 看涨/看跌 |
| 三白兵 / 三只乌鸦 | 持续 |
| 十字星 | 犹豫/反转 |

### 量能因子 (来源: Joseph Granville)

| 因子 | 说明 |
|------|------|
| 量比 | 当日量 / 5日均量 |
| 量价配合度 | 价涨量增/价跌量缩 |
| 地量/天量 | 极端量能信号 |
| 连续缩量 | 蓄力/衰竭 |
| OBV趋势 | 资金流向 |

### MACD因子 (来源: Gerald Appel, 1979)

| 因子 | 说明 |
|------|------|
| 金叉/死叉 | DIF穿越DEA |
| 零轴位置 | 强弱判断 |
| 顶/底背离 | 趋势衰竭 |
| 柱状体变化 | 动量方向 |

## 策略说明

### 策略1: MACD金叉+量能确认
- **条件**: 金叉 + 量比>1.5 + 站上5日线
- **止盈**: +15% 或 死叉
- **止损**: -7% 或 跌破金叉日低点

### 策略2: 底背离+地量反转
- **条件**: MACD底背离 + 地量 + 看涨K线
- **止盈**: 0.618回撤位
- **止损**: 最低价×0.97

### 策略3: 放量突破
- **条件**: 突破20日高点 + 量>2倍均量 + MACD零轴上
- **止盈**: 突破幅度×1.5
- **止损**: 前高位置

### 策略4: 缩量回踩均线
- **条件**: 多头排列 + 回踩MA10/20 + 连续3日缩量 + 止跌K线
- **止盈**: 前高 或 +10%
- **止损**: MA20×0.97

### 策略5: 顶背离+天量见顶
- **条件**: MACD顶背离 + 天量 + 看跌K线
- **操作**: 卖出
- **止损**: 最高价×1.03

### 策略6: 周线趋势确认
- **条件**: 周线金叉 + 周放量 + 突破4周高点
- **止盈**: 周线死叉
- **止损**: 金叉周低点

## ⚠️ 风险提示

**本系统仅供学习和参考，不构成任何投资建议。**

- 技术分析有固有局限性，无法预测突发事件
- 历史表现不代表未来收益
- 建议结合基本面分析和市场环境综合判断
- 严格执行止损纪律，控制单次交易风险在总资金的2-5%
