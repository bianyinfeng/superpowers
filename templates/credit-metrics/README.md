# CreditMetrics Excel 模板

本目录新增了一份可直接打开的 Excel 模板：

- `credit_metrics_single_factor_template.xlsx`

## 模板内容

该模板按经典 CreditMetrics 思路，提供了以下工作表：

1. `说明`：使用步骤、关键假设与扩展提示。
2. `参数`：持有期、置信度、模拟次数、无风险利率。
3. `评级迁移`：评级迁移矩阵与累计迁移概率。
4. `利差假设`：不同评级对应的信用利差假设。
5. `组合输入`：债项/借款人基础信息、回收率、系统因子权重。
6. `状态价值`：各评级状态下的一年后价值、解析期望价值与波动率。
7. `模拟`：单因子高斯框架下的 Monte Carlo 场景、迁移结果与组合损失。
8. `结果`：当前组合价值、解析期望、模拟均值、波动率、VaR、ES 等指标。

## 建模假设

- 采用 **一年持有期** 的 CreditMetrics 风格估值框架。
- 迁移风险使用 **单系统因子 + 个体因子** 的高斯结构近似实现。
- 非违约状态价值通过“票息 + 剩余现金流贴现”计算。
- 违约状态价值使用 `面值 × 回收率` 近似。
- 当前模板预置了 **10 个债项槽位** 与 **500 条模拟场景**，默认启用前 200 条场景。

## 使用方式

1. 在 `参数` 中调整持有期、置信度、模拟次数与无风险利率。
2. 在 `评级迁移` 中替换为你自己的迁移矩阵。
3. 在 `利差假设` 中填入各评级远期/持有期末估值所需利差。
4. 在 `组合输入` 中录入债项名称、评级、票息、期限、回收率和系统因子权重。
5. 打开 `结果` 工作表查看组合层面的期望价值、标准差、VaR 和 ES。

## 扩展建议

- 若需要更多债项，可按 `模拟` 中每个债项的 5 列结构继续向右复制。
- 若需要更多场景，可继续向下复制 `模拟` 工作表中的公式行，并同步调整 `参数` 中的模拟次数。
- 若要切换到多因子或显式相关矩阵版本，可在当前模板基础上替换 `模拟` 工作表中的因子生成逻辑。
