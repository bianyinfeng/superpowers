## 1. 基础概念

### 什么是计量经济学模型？

计量经济学模型就像一个"数学翻译器"，它把经济现象之间的关系用数字和公式表达出来。

**类比理解：** 想象你在研究"天气对冰淇淋销量的影响"。你可能直觉上知道"天越热，冰淇淋卖得越好"，
但计量模型能告诉你：**"温度每升高1度，冰淇淋日销量大约增加50支"**，并且告诉你这个结论有多可靠。

### 关键统计指标

| 指标 | 含义 | 通俗理解 |
|------|------|----------|
| **R²（拟合优度）** | 模型能解释多少比例的变动 | 好比考试得分。R²=80%意味着模型能解释80%的变化，剩余20%是未知因素 |
| **P值** | 某个因素"真的有影响"的可靠程度 | P<0.05表示有95%以上的把握认为该因素确实有效果 |
| **系数** | 某因素变化1单位时，结果会变化多少 | 类似"配方"中每种原料的用量 |
| **t统计量** | 系数的显著性检验值 | |t|越大，越确信这个因素确实有影响 |
| **相关系数** | 两个变量的线性关系强度(-1到+1) | +1=完全同步，-1=完全反向，0=无关 |

### 显著性星号含义

- ⭐⭐⭐ (***) : P < 0.01，非常显著——99%以上确信有效果
- ⭐⭐ (**) : P < 0.05，显著——95%以上确信有效果
- ⭐ (*) : P < 0.10，弱显著——90%以上确信有效果
- 无星号：统计上不显著，该因素可能没有实质影响

## 2. 美国国债监测模型

### 2.1 什么是国债收益率？

美国国债是美国政府发行的"借条"。收益率就是你借钱给美国政府能获得的年化回报率。

**关键点：** 国债价格和收益率反向运动。当很多人想买国债（避险需求高），价格上涨，收益率就下降。

### 2.2 收益率曲线

收益率曲线显示不同到期时间（1个月到30年）国债的收益率水平。

**正常形状（向上倾斜）：** 借期越长，利率越高——因为长期有更多不确定性，投资者要求更高补偿。

**倒挂（向下倾斜）：** 短期利率高于长期利率——这是经济衰退的重要预警信号！历史上，2年/10年收益率倒挂后6-18个月内美国经济几乎都进入了衰退。

### 2.3 模型变量解释

| 变量 | 含义 | 对10Y收益率的影响 |
|------|------|-------------------|
| **联邦基金利率** | 美联储设定的银行间隔夜拆借利率 | 加息→短端利率上升→可能推高长端 |
| **通胀预期** | 市场对未来通胀的预测 | 通胀预期上升→投资者要求更高收益率 |
| **QE规模** | 美联储购买国债的规模 | QE增加→国债被大量买入→收益率被压低 |
| **期限利差** | 10Y收益率 - 2Y收益率 | 利差收窄/倒挂=衰退信号 |

### 2.4 如何理解模型结果

- **如果联邦基金利率系数为正(如+0.5)：** 美联储每加息1个百分点，10年期收益率平均上升0.5个百分点
- **如果QE规模系数为负(如-0.3)：** 美联储资产负债表每扩大1万亿美元，10年期收益率平均下降0.3个百分点

### 2.5 实际应用

- **债券投资者：** 预判利率走向，决定久期配置
- **房贷借款人：** 10Y收益率直接影响30年固定利率房贷
- **经济观察者：** 收益率曲线倒挂是最可靠的衰退领先指标之一

## 3. 美元指数监测模型

### 3.1 什么是美元指数(DXY)？

美元指数衡量美元相对于一篮子主要货币（欧元57.6%、日元13.6%、英镑11.9%等）的综合强弱程度。DXY=100为基准，>100表示美元偏强。

### 3.2 理论基础

**利率平价理论：** 高利率国家的货币倾向走强，因为全球资金追逐更高收益。

**购买力平价理论：** 长期来看，汇率应该反映两国物价水平的差异。

**国际收支方法：** 贸易顺差/逆差、资本流动共同决定货币供需。

### 3.3 模型变量解释

| 变量 | 含义 | 对美元的影响 |
|------|------|-------------|
| **实际利率** | 名义利率 - 通胀率 | 实际利率越高，美元吸引力越大→美元走强 |
| **贸易差额** | 出口 - 进口 | 贸易逆差扩大=美元流出增多→美元走弱 |
| **资本流动** | 外国资金净流入美国的规模 | 资金净流入=对美元需求增加→美元走强 |
| **美联储政策利率** | 联邦基金利率 | 加息=美元资产回报提高→美元走强 |

### 3.4 "美元微笑曲线"

美元在两种情况下走强：
1. **全球经济非常好** → 美国经济领先全球，资金追逐美国高回报
2. **全球经济非常差** → 避险需求，资金涌入美元避风港

美元在中间状态（全球温和复苏但美国不突出）时走弱。这就是"微笑"的形状。

### 3.5 实际应用

- **出口企业：** 美元走强不利于美国出口竞争力
- **新兴市场投资者：** 美元走强通常对新兴市场资产构成压力
- **跨国公司：** 汇率波动影响海外收入折算

## 4. 黄金价格监测模型

### 4.1 黄金的特殊性

黄金既是商品，也是货币，更是"终极避险资产"。它不产生利息，但在通胀、战争、金融危机时能保值。

### 4.2 核心定价逻辑

**黄金的最大"竞争对手"是生息资产。** 当持有国债能获得可观的实际回报时，不产生利息的黄金就不那么有吸引力了。

**核心公式（直觉版）：** 金价 ≈ 通胀保护 + 避险溢价 - 持有机会成本(实际利率)

### 4.3 模型变量解释

| 变量 | 含义 | 对金价的影响 |
|------|------|-------------|
| **实际收益率** | 最重要因子！持有黄金的机会成本 | 实际利率下降→金价上涨（强负相关） |
| **美元指数** | 黄金以美元计价 | 美元走弱→金价上涨（需要更多美元买同样的黄金） |
| **VIX恐慌指数** | 市场恐慌程度 | 恐慌上升→避险买盘→金价上涨 |
| **央行购金量** | 各国央行的黄金储备增购 | 结构性需求增加→支撑金价 |
| **通胀预期** | 对未来物价上涨的预期 | 通胀预期上升→黄金作为通胀对冲工具需求增加 |
| **地缘风险** | 战争、制裁、政治动荡等 | 地缘紧张→避险需求→金价短期飙升 |

### 4.4 近年特殊现象

2022年以来，即使实际利率大幅上升，金价依然坚挺甚至创新高。原因：
- 全球央行（特别是中国、印度、土耳其）大规模购金
- 去美元化趋势下的储备多元化需求
- 地缘政治风险持续高企

这说明传统的"实际利率"单因子模型需要加入"央行购金"和"地缘风险"等新变量。

### 4.5 实际应用

- **资产配置：** 黄金是投资组合中重要的分散风险工具，通常配置5-15%
- **通胀对冲：** 长期来看黄金能保持购买力
- **危机保险：** 在极端风险事件中提供保护

## 5. 通胀监测模型

### 5.1 什么是通胀？

通胀就是"东西变贵了"——同样一笔钱能买到的东西变少了。通常用CPI（消费者价格指数）来衡量。

### 5.2 关键通胀指标

| 指标 | 全称 | 特点 |
|------|------|------|
| **CPI总体** | Consumer Price Index | 包含所有消费品，但受食品能源波动影响大 |
| **核心CPI** | 剔除食品和能源的CPI | 更好反映趋势性通胀，政策参考价值更高 |
| **PCE平减指数** | 个人消费支出价格指数 | **美联储首选通胀指标**，权重更新更灵活 |
| **PPI** | 生产者价格指数 | 领先指标，生产成本上升未来可能传导到消费端 |
| **通胀预期** | 市场对未来5年通胀的预测 | 若脱锚（远离2%），美联储会强力干预 |

### 5.3 通胀的三大成因

#### 1. 需求拉动型通胀
- **原因：** 过多的货币追逐有限的商品
- **典型场景：** 大规模财政刺激后，消费者手中现金增多，争相消费推高价格
- **指标：** M2货币供应量快速增长

#### 2. 成本推动型通胀
- **原因：** 原材料、能源等生产成本上升
- **典型场景：** 油价飙升→运输成本增加→所有商品涨价
- **指标：** PPI上升、原油价格上涨

#### 3. 工资-价格螺旋
- **原因：** 劳动力短缺→工资上涨→企业提价→工人要求更高工资→循环往复
- **典型场景：** 失业率极低时，企业招工困难，不得不加薪
- **指标：** 工资增速、非农就业数据

### 5.4 模型变量解释

| 变量 | 含义 | 对CPI的影响 |
|------|------|-------------|
| **工资增速** | 劳动者收入的年增长率 | 工资涨→企业成本涨→消费品涨价 |
| **M2货币供应** | 广义货币存量 | M2超发→流动性泛滥→需求过热→涨价 |
| **原油价格** | 国际原油价格 | 油价涨→运输+生产成本涨→物价涨 |
| **住房CPI** | 租金和等价租金变化 | 占CPI权重~33%，滞后房价6-12个月 |

### 5.5 美联储2%目标

为什么是2%而不是0%？

- **适度通胀是健康的：** 鼓励消费和投资（钱不花会贬值）
- **防止通缩陷阱：** 日本90年代的教训——通缩导致消费和投资萎缩
- **给货币政策留空间：** 正常通胀时维持正利率，危机时才有降息空间

### 5.6 实际应用

- **固定收入者：** 通胀侵蚀购买力，需要关注工资能否跟上物价
- **投资者：** 高通胀时现金贬值，需要配置实物资产(房产、黄金、股票)
- **房贷借款人：** 高通胀→高利率→房贷成本增加
- **美联储观察者：** 通胀走势决定加息/降息节奏

## 6. 计量经济学方法说明

### 6.1 OLS回归（最小二乘法）

**目标：** 找出一条"最佳拟合线"来描述因变量(Y)和自变量(X)之间的关系。

**公式：** Y = β₀ + β₁X₁ + β₂X₂ + ... + ε

**通俗理解：** 就像在散点图上画一条直线，让所有点到这条线的"距离之和"最小。

**局限性：**
- 假设关系是线性的（现实中可能是非线性）
- 假设误差服从正态分布
- 可能存在遗漏变量偏误（有重要因素没纳入模型）
- 相关不等于因果（两个变量可能同时受第三个因素影响）

### 6.2 相关性分析

**目的：** 衡量两个变量是否"同涨同跌"或"一涨一跌"。

**解读相关系数(r)：**
- r = +0.8 ~ +1.0：强正相关（几乎同步运动）
- r = +0.5 ~ +0.8：中等正相关
- r = -0.5 ~ +0.5：弱相关或无关
- r = -0.8 ~ -0.5：中等负相关
- r = -1.0 ~ -0.8：强负相关（几乎完全反向）

**重要提醒：** 相关不等于因果！冰淇淋销量和溺水事故正相关，但原因是夏天——不是冰淇淋导致溺水。

### 6.3 格兰杰因果检验

**目的：** 检验X的过去值能否帮助预测Y的未来值。

**通俗理解：** 如果加入了"昨天的X"之后，对"今天的Y"的预测变得更准了，就说"X格兰杰因果Y"。

**注意：** 这仍然不是真正的因果关系，只是"预测上的因果"。

## 7. 如何阅读模型结果

### 7.1 回归结果表

当你看到一个回归结果表时，按以下顺序阅读：

1. **先看R²：** 模型整体好不好？
   - >70%：解释力较强，模型比较可靠
   - 40-70%：中等，还有重要因素没纳入
   - <40%：解释力有限，结论需谨慎

2. **再看P值和星号：** 哪些因素真的重要？
   - 有***的变量是确定有效果的
   - 无星号的可能只是噪音

3. **最后看系数方向和大小：** 有多大影响？
   - 正系数=正向影响，负系数=负向影响
   - 系数越大，影响越大（但要注意变量的单位）

### 7.2 相关性矩阵

- 找到颜色最深的格子（绿色=强正相关，红色=强负相关）
- 这些是最值得关注的变量关系
- 但记住：相关性只是线索，不是结论

### 7.3 时间序列图表

- 看趋势方向（上升、下降、震荡）
- 看拐点（什么时候方向变了？对应什么事件？）
- 看不同序列之间的同步/领先/滞后关系

### 7.4 常见陷阱

1. **过度拟合：** 模型在历史数据上表现好，但预测未来可能不准
2. **遗漏变量：** 重要因素没被纳入模型，导致系数偏误
3. **结构性变化：** 过去的关系在未来可能不成立（例如疫情改变了很多经济关系）
4. **尾部风险：** 极端事件（黑天鹅）不在模型预测范围内

## 附录：常用经济学术语速查

| 术语 | 解释 |
|------|------|
| **美联储(Fed)** | 美国央行，负责货币政策（调控利率和货币供应） |
| **QE(量化宽松)** | 央行印钱买债券，向市场注入流动性 |
| **QT(量化紧缩)** | QE的反面，央行缩表回收流动性 |
| **TIPS** | 通胀保护国债，收益率跟随通胀调整 |
| **盈亏平衡利率** | TIPS隐含的市场通胀预期 |
| **实际利率** | 名义利率 - 通胀率；反映资金的真实购买力回报 |
| **DXY** | 美元指数，衡量美元相对六种货币的综合汇率 |
| **VIX** | 恐慌指数，衡量市场对未来30天波动的预期 |
| **PCE** | 个人消费支出，美联储首选通胀衡量标准 |
| **期限利差** | 长期国债收益率 - 短期国债收益率 |
| **收益率曲线倒挂** | 短期利率高于长期利率，衰退预警信号 |
| **格兰杰因果** | 统计意义上的"预测性因果"，非真实因果 |
