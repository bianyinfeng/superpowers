# Xray 核心协议可视化学习互动教程

> 基于 OSI 七层模型，从代码层面深入理解 Xray 支持的各种协议原理，并设计一个全新的高可用、高安全性协议。

## 🎯 学习目标

完成本教程后，你将能够：

1. **理解** Xray 核心在 OSI 每一层的工作原理
2. **掌握** 路由、DNS、TLS、证书等核心机制的代码实现
3. **分析** 各种代理协议的设计思路与安全特性
4. **设计** 符合现代安全标准的新协议

## 📖 如何使用本教程

1. **顺序阅读**：按章节顺序，从底层到高层理解整个协议栈
2. **交互练习**：每章包含 Mermaid 流程图和代码示例，可直接在支持 Mermaid 的 Markdown 渲染器中查看
3. **动手实践**：每章末尾提供配置示例和思考题
4. **综合设计**：最后一章将前面所有知识融合，设计全新协议

## ⚙️ 前置知识

- 基本的网络知识（TCP/IP 协议栈）
- Go 语言基础（Xray 核心使用 Go 编写）
- 密码学基本概念（对称/非对称加密）
