## 四个看板的内在联系

这四个看板并非独立孤立，它们共同描述宏观经济的一个完整传导链：

```
通胀数据（通胀看板）
      ↓
影响美联储加息/降息决策
      ↓
政策利率变化（美债看板：政策利率模块）
      ↓
影响实际利率和收益率曲线（美债看板：收益率曲线 & 实际利率）
      ↓
影响美元强弱（美元看板：DXY + 利差）
      ↓
影响全球资产价格，尤其是黄金和大宗商品（黄金大宗看板）
      ↓
大宗商品价格变化反过来影响通胀（通胀看板：PPI领先指标）
      ↑___________________________________________________↩
```

## 建议阅读顺序

1. **先读通胀看板文档**：理解"为什么美联储要做任何事情"
2. **再读美债看板文档**：理解"美联储的工具和市场反应"
3. **再读美元看板文档**：理解"流动性如何影响全球资金流向"
4. **最后读黄金大宗文档**：理解"资产价格的实际响应"

## 核心记忆口诀

- **通胀**：`PPI 领先 CPI，核心 PCE 是美联储的靶心`
- **美债**：`收益率曲线倒挂 = 衰退预警，实际利率是所有资产的重力`
- **美元**：`美元和大多数风险资产负相关，利率差驱动中期走势`
- **黄金**：`实际利率是重力，美元是风向，通胀预期是风帆`
