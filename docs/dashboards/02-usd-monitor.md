## 1. 看板概述与使用目的

**这个看板解决什么问题？**

美元是全球储备货币，全球约60%的外汇储备、约85%的外汇交易、约50%的国际贸易以美元计价。美元的强弱直接影响：
- **新兴市场国家：** 美元升值→这些国家偿还美元债务成本上升，资本外流，本币贬值
- **大宗商品：** 大宗商品以美元计价，美元升值→商品价格通常下跌（黄金、原油等）
- **美国企业：** 美元升值→美国出口竞争力下降，跨国公司海外收入折算后减少

这个看板帮助你回答：
1. **美元供应是扩张还是收缩？** 影响全球流动性
2. **美元在全球走强还是走弱？** 影响跨资产价格
3. **美联储的政策立场在向哪里走？** 决定美元中期方向

## 2. 宏观背景：美元的特殊地位

### 2.1 布雷顿森林体系遗产

1944年，布雷顿森林协议建立了以美元为中心的国际货币体系。虽然1971年尼克松宣布美元与黄金脱钩，但美元的主导地位延续至今，原因包括：
- 美国是全球最大经济体和最大贸易国之一
- 美国金融市场规模全球最大，流动性最好
- 全球大宗商品（石油、铜、小麦等）以美元定价
- 美债是全球最重要的"无风险资产"

### 2.2 美元潮汐效应（Dollar Cycle）

美元强弱对全球经济有"潮汐效应"：
- **美元升值周期：** 全球美元流动性收紧，新兴市场面临资本外逃，美元计价资产承压
- **美元贬值周期：** 全球美元流动性扩张，新兴市场获得喘息，大宗商品受益

## 3. 模块一：美元指数（DXY）

### 3.1 DXY 是什么？

**美元指数（DXY / US Dollar Index）** 是美元相对一篮子主要货币的加权汇率指数，基准值为 100（1973年设定）。

**DXY 的货币篮子构成（固定权重）：**

| 货币 | 权重 |
|------|------|
| 欧元（EUR） | **57.6%** |
| 日元（JPY） | 13.6% |
| 英镑（GBP） | 11.9% |
| 加元（CAD） | 9.1% |
| 瑞典克朗（SEK） | 4.2% |
| 瑞士法郎（CHF） | 3.6% |

> **注意：** DXY 没有包含人民币、韩元、澳元等，所以它主要代表美元对发达经济体货币的强弱。

### 3.2 DXY 的历史区间参考

| DXY 水平 | 历史解读 |
|---------|---------|
| < 90 | 美元相对弱势区间 |
| 90~100 | 历史中性区间 |
| 100~110 | 美元偏强 |
| > 110 | 历史高位强势（2022年最高达到 114） |

### 3.3 驱动 DXY 的核心因素

1. **美联储 vs 其他央行的利率差异**
   - 美联储加息而欧央行不动 → 美元相对欧元升值 → DXY 上涨
   - 公式：DXY 方向 ≈ 美国利率水平 - 贸易伙伴国平均利率水平

2. **避险情绪（Risk-off/Risk-on）**
   - 全球市场恐慌时（Risk-off）：资金涌入美元避险 → DXY 上涨
   - 全球风险偏好回升（Risk-on）：资金流出美元 → DXY 下跌

3. **美国经济相对强弱**
   - 美国经济数据强劲 → 美联储保持高利率预期 → 美元走强

4. **美元流动性供给**
   - 美联储 QE（印钱）→ 美元供给增加 → DXY 倾向走弱
   - 美联储 QT（缩表）→ 美元供给收缩 → DXY 倾向走强

## 4. 模块二：美联储资产负债表

### 4.1 美联储资产负债表是什么？

美联储通过买卖资产创造和回收基础货币。其资产负债表规模就是"美元的水龙头"。

**资产侧（美联储持有的资产）：**
- 美国国债（占大头）
- 机构抵押贷款支持证券（MBS）
- 其他

**负债侧（美联储创造的货币）：**
- 商业银行在美联储的准备金存款
- 流通中的美联储纸币（现金）
- 逆回购协议（RRP）

### 4.2 QE 与 QT 的效果

**量化宽松（QE）：美联储扩表**
- 美联储在公开市场买入国债和MBS
- 向银行体系注入准备金（基础货币增加）
- 效果：压低长端利率，推高风险资产价格

**量化紧缩（QT）：美联储缩表**
- 美联储不再续投到期债券（让资产自然到期）
- 从银行体系回收准备金
- 效果：长端利率上行压力，流动性收缩

### 4.3 定量规模参考

| 时期 | 美联储资产规模 | 说明 |
|------|-------------|------|
| 2008年金融危机前 | ~9000亿美元 | 正常水平 |
| 2014年 QE3 结束后 | ~4.5万亿美元 | 三轮 QE 后 |
| 2020年 COVID QE 后 | ~8.9万亿美元（峰值） | 史上最大规模扩表 |
| 2024年 QT 进行中 | ~7万亿美元 | 持续缩表 |

## 5. 模块三：货币供应量（M1/M2）

### 5.1 货币层次

| 指标 | 定义 | 直觉理解 |
|------|------|---------|
| M0 | 流通中现金 | 口袋里的钱 |
| M1 | M0 + 活期存款 | 马上可花的钱 |
| **M2** | M1 + 储蓄存款 + 货币市场基金 | **最常用，代表广义货币** |
| M3 | M2 + 大额定期存单等 | 更广义（美联储已停止公布） |

### 5.2 M2 增速与通胀的关系

货币数量论（MV = PQ）告诉我们：
- M = 货币量，V = 货币流通速度，P = 价格水平，Q = 经济产出
- **当 M2 增速远超经济增速时，多出来的货币会推高物价（通胀）**

历史数据：
- 2020~2021年，美国 M2 同比增速一度超过 **27%**（历史最高）
- 随后2022年通胀飙升至9.1%（历史高点）
- 2022~2023年 M2 同比转负（历史罕见）
- 通胀随后从峰值回落

### 5.3 M2 与市场的关系

```
M2 增速加快 → 市场流动性充裕 → 资产价格上涨压力
M2 增速放缓或负增长 → 流动性收缩 → 资产价格承压
```

## 6. 模块四：美元流动性指标

### 6.1 全球美元流动性综合指标

看板中可能有一个综合美元流动性指标，通常由以下几部分构成：
- 美联储资产负债表规模
- 财政部一般账户（TGA）余额（负向：TGA 余额越高，市场流动性越低）
- 美联储逆回购余额（ON RRP）（负向：代表多余资金停放在美联储）

**公式：美元流动性 ≈ 美联储资产规模 - TGA余额 - ON RRP余额**

| 情况 | 美元流动性 | 市场影响 |
|------|----------|---------|
| 美联储扩表 + TGA下降 + RRP下降 | 强烈流动性扩张 | 风险资产大涨 |
| 美联储缩表 + TGA上升 + RRP上升 | 强烈流动性收缩 | 风险资产承压 |

### 6.2 TED 利差（信用风险温度计）

**TED 利差 = 3个月LIBOR（银行间拆借利率）- 3个月美国国库券收益率**

- 正常水平：20~50bp（0.2%~0.5%）
- 超过 100bp：市场出现明显压力
- 2008年金融危机期间：峰值超过 450bp

TED 利差越高，代表银行间信用风险越大，美元流动性越紧张。

### 6.3 美联储美元互换额度（Swap Lines）

金融危机时，美联储向主要央行（欧央行、日本央行等）提供美元互换额度，帮助海外金融机构获取美元流动性。互换额度的使用量激增通常代表全球美元流动性紧张。

## 7. 模块五：实际利率与利差

### 7.1 美元的利差驱动

美元最重要的驱动力之一是**利差**：美国利率 vs 其他主要经济体利率。

**利差套利（Carry Trade）逻辑：**
- 如果美国联邦基金利率 5.5%，而日本政策利率 0.1%，利差 5.4%
- 投资者会借日元、买美元资产，获取利差收益
- 这种行为推高美元需求 → DXY 上涨

**影响 DXY 的主要利差：**

| 利差 | 影响 |
|------|------|
| 美-欧（2年期） | 最重要，权重57.6% |
| 美-日（2年期） | 关键，"日元套利"敏感度极高 |
| 美-英（2年期） | 次要 |

### 7.2 实际利率与 DXY

**美国实际利率（TIPS）越高 → 持有美元资产越有吸引力 → 美元走强**

```
美国实际利率 vs 其他国家实际利率差扩大
              ↓
资金流向美国（购买美债、美元资产）
              ↓
美元需求上升，DXY 走强
              ↓
大宗商品（黄金、原油）以美元计价，价格承压
新兴市场面临资本外流压力
```

## 8. 模块六：外汇储备与美元需求

### 8.1 全球外汇储备的美元占比

- 全球央行外汇储备中，美元占比约 **58~60%**（近年有所下降）
- 美元储备占比下降趋势：2000年71% → 2024年约59%
- 这被称为"美元去中心化"（De-dollarization）趋势，但速度非常缓慢

### 8.2 石油美元体系（Petrodollar）

- 沙特及OPEC国家以美元定价出售石油（petrodollar 体系，1973年以来）
- 石油生产国获得美元 → 将美元投资于美国国债 → 形成美元需求循环
- 如果石油美元体系松动（如人民币结算石油），长期对美元不利

### 8.3 如何读外汇储备数据

- IMF 每季度公布 COFER 报告（全球官方外汇储备构成）
- 美元占比持续下降 → 长期美元弱势信号
- 主要新兴市场央行增持欧元、人民币、黄金 → 分散美元风险

## 9. 核心传导逻辑

### 9.1 美元与其他资产的联动关系

```
美元走强（DXY 上涨）时：
  ├─ 黄金：通常下跌（以美元计价，变贵了）
  ├─ 原油：通常下跌（同上）
  ├─ 新兴市场股票：通常下跌（资本外流）
  ├─ 美国出口企业：盈利承压（竞争力下降）
  └─ 美国进口消费品：价格下降（通胀减弱）

美元走弱（DXY 下跌）时：
  ├─ 黄金：通常上涨
  ├─ 原油：通常上涨
  ├─ 新兴市场：获益（资本流入，本币升值）
  └─ 美国制造业：出口竞争力提升
```

### 9.2 美联储政策周期 vs 美元周期

| 美联储阶段 | M2 | 实际利率 | DXY 倾向 |
|----------|-----|---------|---------|
| 加息初期 | 增速放缓 | 快速上升 | 走强 |
| 加息尾声/见顶 | 停止收缩 | 见顶 | 触顶 |
| 降息预期升温 | 开始扩张 | 下降 | 走弱 |
| 降息周期 | 扩张 | 下降 | 走弱，但若衰退避险则复杂 |

## 10. 投资决策框架

### 10.1 五步看懂美元看板

**第一步：DXY 当前位置**
- DXY 处于历史高位（>105）还是低位（<90）？
- 短期趋势：是在上升通道还是下降通道？

**第二步：驱动力分析**
- 是美联储因素（利率差）还是避险因素（Risk-off）驱动的美元走强？
- 避险驱动的美元强是短期的；利率差驱动的美元强是中期结构性的

**第三步：M2 和流动性**
- M2 同比增速是正还是负？
- 美联储资产负债表是在扩张还是收缩？

**第四步：美元流动性公式**
- 美联储资产规模 - TGA - RRP = 净流动性
- 净流动性上升 → 风险资产顺风

**第五步：综合判断**

| 信号组合 | 美元方向 | 对其他资产影响 |
|---------|---------|--------------|
| 美联储加息 + DXY 上涨 + M2 下降 | 美元强势周期 | 黄金/新兴市场承压 |
| 美联储降息预期 + DXY 下跌 + M2 上升 | 美元弱势周期 | 黄金/商品/新兴市场受益 |
| DXY 快速上涨（避险） | 短期美元冲高 | 全球风险资产普跌 |

### 10.2 关键阈值速查

| 指标 | 信号区间 | 解读 |
|------|---------|------|
| DXY > 105 | 美元强势 | 对黄金/大宗/新兴市场施压 |
| DXY < 90 | 美元弱势 | 黄金/新兴市场顺风 |
| M2 同比 > 10% | 流动性宽松 | 资产价格上涨动力 |
| M2 同比 < 0% | 流动性紧缩 | 资产价格承压 |
| TED 利差 > 100bp | 信用危机风险 | 美元流动性严重紧张 |
| 美联储资产负债表环比扩大 | QE 或紧急操作 | 流动性注入，风险资产受益 |

## 11. 综合案例分析

### 案例一：2022年美元超强周期

**背景：** 美联储史上最快加息，欧洲面临能源危机，全球避险情绪升温

**看板变化轨迹：**
- DXY 从年初95，飙升至9月的114（历史高位）
- 美联储资产负债表开始缩表（从8.9万亿降至7.7万亿）
- M2 同比增速从27%急降至接近0
- 美-欧利率差：美国加息幅度远超欧央行 → 欧元兑美元跌至平价以下

**对其他资产的影响：**
- 黄金：跌约15%（实际利率上升 + 美元走强双重打压）
- 原油：前半年大涨（通胀），后半年在强美元下回调
- 新兴市场股指：普遍下跌15~30%

### 案例二：2020年美联储无限 QE

**背景：** COVID-19 冲击，美联储开启史无前例宽松，M2 增速27%

**看板变化轨迹：**
- 美联储资产负债表从4.2万亿在3个月内扩张至7万亿
- M2 同比激增，年增速超过25%（历史记录）
- DXY 从103高点急跌至90以下（美元流动性大幅释放）
- 全球流动性指标大幅上升

**对其他资产的影响：**
- 黄金：2020年从1500冲至2067（历史新高）
- 纳斯达克：2020年全年涨约44%
- 新兴市场：大幅受益，资本涌入
