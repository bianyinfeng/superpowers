## 1. 看板概述与使用目的

**这个看板解决什么问题？**

黄金是一种特殊的资产：它没有现金流、没有股息，但几千年来一直被人类视为价值储藏手段。大宗商品（原油、铜、铁矿石、农产品等）则是现实经济的"体温计"，价格反映全球经济的冷热。

这个看板帮助你回答：
1. **黄金应该涨还是跌？** 实际利率和美元是两大核心驱动因素
2. **全球经济是在扩张还是收缩？** 铜价和铜金比是重要的领先指标
3. **通胀预期是在上升还是下降？** 大宗商品价格变化是通胀的领先指标
4. **地缘政治风险有多高？** 黄金对避险需求非常敏感

## 2. 宏观背景：黄金的本质是什么？

### 2.1 黄金的四种功能

| 功能 | 解释 | 举例 |
|------|------|------|
| **价值储藏** | 跨越历史的购买力保存工具 | 2000年前黄金买一件好袍子，今天同量黄金还能买一件好衣服 |
| **避险资产** | 战争、金融危机时的"安全港" | 2008年金融危机，黄金逆势上涨 |
| **反美元资产** | 美元贬值时黄金通常升值 | 2020年美联储大放水，黄金创历史新高 |
| **通胀对冲** | 真实购买力的保护工具 | 历史上黄金长期跑赢通胀 |

### 2.2 黄金的定价框架（最重要！）

```
黄金价格 ↑  当：
  1. 美国实际利率下降（持有黄金的机会成本降低）
  2. 美元走弱（以美元计价的黄金，美元弱则更便宜）
  3. 通胀预期上升（黄金作为通胀对冲工具需求上升）
  4. 地缘政治/金融风险上升（避险需求）
  5. 央行增持黄金储备（官方需求）
```

**核心公式（近似）：**

```
黄金价格 ∝ 1 / 实际利率
```

当10年期实际利率（TIPS收益率）= -1%，黄金涨；实际利率 = +2%，黄金跌。
这是黄金最强的定价逻辑，解释了约70%的黄金价格波动。

## 3. 模块一：黄金现货价格

### 3.1 黄金计价单位

| 单位 | 换算 | 常用场景 |
|------|------|---------|
| 美元/金衡盎司（troy oz） | 1金衡盎司 = 31.1035克 | 国际金融市场主流 |
| 美元/克 | 盎司价 / 31.1 | 日常买卖计算 |
| 人民币/克 | 换算后 | 中国投资者常用 |

### 3.2 历史价格区间参考

| 时期 | 金价（美元/盎司） | 背景 |
|------|----------------|------|
| 2000年 | ~280 | 历史低点，实际利率高 |
| 2008年 QE 前 | ~1000 | 油价通胀驱动 |
| 2011年 | 1920（当时历史高点） | 欧债危机 + 美联储 QE |
| 2018~2019年 | 1200~1550 | 美联储加息周期，实际利率较高 |
| 2020年 8月 | 2075（新历史高点） | COVID QE，实际利率 -1% |
| 2022年 | 1620~2000（波动） | 实际利率快速上升，金价承压 |
| 2024~2025年 | 2300~3500+ | 地缘风险 + 央行购金 + 降息预期 |

### 3.3 看黄金价格要注意的陷阱

- 黄金价格以美元计价，因此"金价上涨"有时候只是"美元贬值"的反映
- 真正要看的是**黄金的实际购买力**：金价 / 通胀调整后的价格指数
- **黄金兑其他货币（如兑人民币、欧元）** 有时候走势完全不同于美元金价

## 4. 模块二：实际利率与黄金

### 4.1 机会成本逻辑

黄金不产生利息或股息。当你持有黄金时，你放弃了持有美国国债（有正实际收益）的机会。这就是**机会成本**。

- 实际利率 = 2%：你买10年期TIPS，保证实际年化收益2%，而黄金给你0。黄金没有吸引力。
- 实际利率 = -1%：连通胀保值债券都是负收益，黄金至少不缩水，黄金有吸引力。

### 4.2 实际利率 vs 金价：历史对比

| 时期 | 10年期TIPS收益率 | 黄金表现 |
|------|----------------|---------|
| 2011~2013年 | 从 -0.5% 升至 +0.5% | 黄金从1920跌至1200 |
| 2018~2019年 | 约 +0.5%~+1% | 黄金从1200缓慢升至1550 |
| 2020~2021年 | 从 0% 降至 -1.1%（历史最低） | 黄金从1500飙升至2075 |
| 2022年 | 从 -1% 急升至 +1.8% | 黄金从2000跌至1620 |
| 2023~2024年 | +2% 附近高位 | 金价异常抗跌，开始脱锚 |

> **2023~2024年的"脱锚"现象：** 实际利率很高但黄金依然上涨。这说明除了实际利率，**央行购金需求**（中国、俄罗斯、印度等新兴市场央行大量增持）和**去美元化趋势**成为新的驱动力。

### 4.3 量化关系参考

粗略规律：实际利率每变动 **1 个百分点**，黄金价格反向变动约 **10%~15%**（非精确，供参考）

## 5. 模块三：美元与黄金

### 5.1 美元-黄金的负相关关系

由于黄金以美元计价，美元走强通常压制金价：

| DXY 变化 | 黄金（一般方向） | 原因 |
|---------|---------------|------|
| DXY 上涨（美元升值） | 下跌 | 同样数量的黄金换算美元后"更贵"，需求减少 |
| DXY 下跌（美元贬值） | 上涨 | 美元购买力下降，黄金储值需求上升 |

> **但这不是绝对定律！** 当避险情绪极度强烈时，美元和黄金可以同涨（如2020年3月COVID冲击初期，两者短暂同时上涨）。

### 5.2 黄金相对强弱评估

**黄金的真实强弱 = 金价涨跌幅 - DXY 涨跌幅的反向贡献**

如果DXY跌了5%，金价涨了5%，这并不意味着黄金"真的变贵"，可能只是美元贬值的镜像。

## 6. 模块四：通胀预期与黄金

### 6.1 盈亏平衡通胀率（Break-even Inflation）

**盈亏平衡通胀率 = 名义国债收益率 - TIPS（实际利率）**

如：10年期名义国债 4.5%，10年期 TIPS 2.2%，盈亏平衡通胀率 = **2.3%**

这代表市场预期未来10年平均每年通胀 2.3%。

| 盈亏平衡通胀率 | 含义 | 对黄金影响 |
|-------------|------|----------|
| > 2.5% | 市场担心高通胀 | 正面（黄金通胀对冲需求上升） |
| 2% 附近 | 通胀预期稳定 | 中性 |
| < 1.5% | 市场担心通缩 | 负面（黄金通胀对冲价值下降） |

### 6.2 通胀对金价的两种相反逻辑

> **这是一个常见困惑点！**

- **短期：** 通胀上升 → 美联储加息 → 实际利率可能上升 → 金价承压（反直觉）
- **长期：** 通胀持续侵蚀美元购买力 → 黄金作为实物资产保值 → 金价上涨

**所以重要的不是通胀本身，而是"通胀是否超过了利率"：**
- 名义利率4%，通胀3%：实际利率+1%，通胀没有击败利率，黄金动力一般
- 名义利率2%，通胀5%：实际利率-3%，通胀远超利率，黄金是最佳选择

## 7. 模块五：大宗商品综合指标

### 7.1 CRB 指数（商品研究局指数）

CRB 指数是一个综合大宗商品价格指数，涵盖能源、金属、农产品等。

**构成：**
- 能源（石油/天然气）：约39%
- 农产品（玉米/大豆/小麦等）：约34%
- 贵金属和工业金属：约20%
- 其他：约7%

CRB 指数上涨 = 全球大宗商品通胀压力上升，通常意味着通胀预期升温，对黄金有阶段性支撑。

### 7.2 大宗商品超级周期

历史上，大宗商品有大约 15~20 年的超级周期：
- **1999~2011年：** 超级牛市（中国工业化带动需求爆炸，铜、铁矿石、原油飙升）
- **2011~2020年：** 熊市（页岩油革命供给冲击，中国增速放缓）
- **2020年至今：** 可能开启新超级周期（能源转型 + 供应链重构 + 去全球化）

### 7.3 大宗商品与通胀的领先关系

**大宗商品通常领先 CPI 约 3~6 个月。**

| PPI（生产者物价指数）变化 | CPI（消费者物价指数）变化 |
|----------------------|----------------------|
| PPI 上涨 3~6个月 → | CPI 跟涨 |
| PPI 下降 3~6个月 → | CPI 跟跌 |

## 8. 模块六：铜金比（经济温度计）

### 8.1 什么是铜金比？

**铜金比 = 铜价（美元/磅） / 金价（美元/盎司）**

或用对数：**ln(铜价) - ln(金价)**

### 8.2 为什么铜金比是经济温度计？

- **铜：** 广泛用于建筑、电子、汽车、电网。铜价上涨反映全球工业需求旺盛，经济扩张
- **黄金：** 避险属性强，经济不好时黄金相对更受欢迎
- **铜金比上升：** 铜比黄金相对更强 → 经济扩张信号
- **铜金比下降：** 黄金比铜更受欢迎 → 经济收缩/避险信号

### 8.3 铜金比的神奇关系：预测美债收益率

研究发现，**铜金比走势与10年期美债收益率高度相关**（相关系数约 0.7~0.8）。

**逻辑链：**
```
铜金比上升 → 经济预期向好 → 
通胀预期上升 → 美联储倾向加息 → 
10年期国债收益率上升
```

**实践应用：**
- 如果铜金比已经大幅上升，但10年期收益率还没有涨，可能有套利机会（收益率要跟涨）
- 如果铜金比已经下降，但收益率还在高位，可能预示收益率要跟跌（看多长债）

### 8.4 定量参考

| 铜金比水平 | 历史对应的10Y美债收益率 |
|----------|---------------------|
| 0.15~0.20 | 低收益率环境（1%~2%） |
| 0.25~0.35 | 中等收益率（2%~3.5%） |
| > 0.40 | 高收益率环境（>3.5%） |

## 9. 模块七：原油市场

### 9.1 为什么关注原油？

原油是大宗商品之王，对通胀有直接影响：
- 能源成本影响几乎所有商品的生产和运输成本
- 油价上涨 → 汽油、天然气涨价 → CPI中能源分项上涨 → 通胀压力
- 通胀上升 → 美联储偏向加息 → 实际利率上升 → 不同资产受影响

### 9.2 原油主要基准价格

| 基准 | 产地 | 特点 |
|------|------|------|
| **WTI（西得克萨斯中质油）** | 美国 | 美国原油的基准价 |
| **Brent（布伦特）** | 北海 | 全球最重要的原油定价基准 |
| **Dubai/Oman** | 中东 | 亚洲市场参考 |

Brent 和 WTI 价差（Brent-WTI spread）反映全球原油运输和供需结构差异。

### 9.3 原油与金价的关系

原油和黄金都有通胀对冲属性，历史上正相关：
- **原油/黄金比率（Oil/Gold Ratio）：** 历史均值约 20（即1盎司黄金可买约20桶原油）
- 如果该比率大幅偏离20，可能存在相对价值机会

## 10. 核心传导逻辑

### 10.1 黄金定价的完整逻辑图

```
宏观因素
  ├─ 美联储政策 ─→ 实际利率（最重要驱动）─→ 黄金价格（负相关）
  ├─ 美元指数（DXY）─────────────────────→ 黄金价格（负相关）
  ├─ 通胀预期（BEI）─────────────────────→ 黄金价格（正相关）
  ├─ 地缘政治风险 ────────────────────────→ 黄金价格（正相关）
  └─ 央行购金 ────────────────────────────→ 黄金价格（正相关）

市场结构因素
  ├─ COMEX期货持仓（净多头/净空头）
  ├─ ETF 持金量（GLD/IAU持仓变化）
  └─ 上海黄金交易所（SGE）溢价
```

### 10.2 大宗商品整体的宏观框架

```
全球经济周期：
  扩张期 → 需求旺盛 → 工业金属（铜、铁矿石）领涨 → CRB 指数上涨
  衰退期 → 需求萎缩 → 工业金属暴跌 → 贵金属相对抗跌
  滞胀期 → 经济停滞 + 高通胀 → 黄金/农产品最强 → 工业金属分化
```

## 11. 投资决策框架

### 11.1 黄金投资时钟

根据实际利率和通胀预期的组合，判断黄金的投资时机：

| 实际利率方向 | 通胀预期方向 | 黄金信号 | 强度 |
|------------|------------|---------|------|
| ↓下降 | ↑上升 | 强烈买入 | ★★★★★ |
| ↓下降 | →稳定 | 买入 | ★★★★ |
| →稳定 | ↑上升 | 中性偏买 | ★★★ |
| ↑上升 | ↑上升（超预期通胀） | 需观察 | ★★ |
| ↑上升 | →稳定或↓ | 卖出/规避 | ★ |

### 11.2 五步看懂黄金大宗看板

**第一步：看10年期 TIPS（实际利率）**
- 实际利率 > 2%：黄金逆风，需要其他强力驱动才能上涨
- 实际利率 < 1%：黄金顺风
- 实际利率 < 0%：黄金最强动力

**第二步：看 DXY**
- DXY 上涨趋势中：黄金受压
- DXY 下跌趋势中：黄金顺风

**第三步：看盈亏平衡通胀率（BEI）**
- BEI 上升：通胀预期升温，黄金对冲需求增加
- BEI 下降：通胀预期降温，黄金对冲吸引力下降

**第四步：看铜金比**
- 铜金比上升（铜强于金）：经济扩张信号，工业金属更受益，贵金属相对弱
- 铜金比下降（金强于铜）：避险/衰退信号，贵金属更受益

**第五步：看央行购金和 ETF 持仓**
- 全球央行净购金：长期结构性支撑（尤其是新兴市场央行）
- ETF 持仓净流入：机构和零售投资者买入信号

### 11.3 速查信号表

| 看板指标 | 信号 | 对黄金的含义 |
|---------|------|------------|
| 10Y TIPS < 0% | 负实际利率 | 强烈看涨黄金 |
| DXY > 105 且上涨 | 美元强势 | 黄金短期承压 |
| BEI > 2.5% | 通胀预期高 | 黄金通胀对冲需求旺 |
| 铜金比持续下降 | 避险情绪升温 | 黄金相对强势 |
| 央行月度购金量 > 50吨 | 官方需求强劲 | 黄金结构性支撑 |
| COMEX 净多头仓位创新高 | 投机多头拥挤 | 短期回调风险 |

## 12. 综合案例分析

### 案例一：2020年黄金超级牛市

**时间线与驱动因素：**

| 时间 | 金价 | 驱动因素 |
|------|------|---------|
| 2020年1月 | ~1560美元 | 基准价格 |
| 2020年3月 | 1480美元（短暂暴跌） | COVID恐慌 → 美元流动性危机，所有资产被抛售 |
| 2020年8月 | 2075美元（历史新高） | 美联储扩表8.9万亿，TIPS降至-1%，DXY跌到90 |

**看板信号分析：**
- 实际利率（TIPS）：从 0% → -1.1%（历史最低）✓ 强烈做多黄金
- DXY：从103 → 90 ✓ 美元大幅走弱，支持黄金
- M2 同比：+27% ✓ 流动性泛滥，资产价格全面上涨
- 央行购金：多国央行增持，需求强劲

**结论：** 三大驱动因素（实际利率、美元、流动性）全部指向做多黄金，历史性机会。

---

### 案例二：2022年黄金熊市

**时间线：**

| 时间 | 金价 | 驱动因素 |
|------|------|---------|
| 2022年3月 | 2050美元（阶段高点） | 俄乌冲突避险需求 |
| 2022年9月 | 1620美元（年内低点） | 美联储激进加息，TIPS升至+1.8%，DXY升至114 |
| 2022年底 | 1800美元 | 加息预期见顶，开始回升 |

**看板信号分析：**
- 实际利率（TIPS）：从 -1% → +1.8%（暴涨2.8个百分点）✗ 极度利空黄金
- DXY：从95 → 114（40年高位）✗ 美元超强，压制金价
- M2 同比：从高位急速下降接近0 ✗ 流动性收缩

**结论：** 所有信号全部指向做空黄金，但由于2022年初俄乌冲突带来地缘避险溢价，金价下跌幅度相对温和（-20%），体现了黄金的避险属性在极端情况下的支撑作用。

> **学习建议：** 记住这个口诀：**"实际利率是金价的重力，美元是金价的风向，通胀预期是金价的风帆。"** 当重力减弱（实际利率降）、风向顺（美元弱）、风帆满（通胀预期高），黄金就会大幅上涨。
